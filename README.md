## About

Flaming Core is a 2D game created using the C programming language and the raylib graphics library. The project was developed collaboratively as part of a university course to demonstrate game development concepts such as movement, physics, collisions, level design, and user interface.

## Technologies

- **C Programming Language**
- **Raylib Graphics Library**
- **Visual Studio 2026**
- **GitHub**

## Features

- 2D gameplay mechanics  
- Multiple levels  
- Physics-based interactions  
- Collision detection system  
- Player controls  
- HUD (Heads-Up Display)  
- Obstacles and core game mechanics 

## Team Project

## Requirements

- Visual Studio 2026
- Raylib (must be installed and configured in Visual Studio)

## How to Run

1. Install and integrate **Raylib** into Visual Studio  
2. Open `GameProject.sln` in Visual Studio  
3. Build the solution (Ctrl + Shift + B)  
4. Run the project (F5)
