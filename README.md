# Flaming Core

A 2D action game developed in C using the raylib library as a university team project.

## About

Flaming Core is a 2D game created using the C programming language and the raylib graphics library. The project was developed collaboratively as part of a university course to demonstrate game development concepts such as movement, physics, collisions, level design, and user interface.

## Technologies

- C
- raylib
- Visual Studio 2026
- GitHub

## Features

- 2D gameplay
- Multiple levels
- Physics and collision system
- Player controls
- HUD (Heads-Up Display)
- Obstacles and game mechanics

This repository contains a university team project developed by a team of students.
